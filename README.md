# releve-web

Les deux pages publiques de Relève, servies par GitHub Pages :

- `index.html` : la page d'installation où mène le code QR d'un billet
  (`…/releve-web/#NIP`). Elle reconnaît le téléphone, ouvre l'App Store ou Google Play
  et fait suivre le NIP jusque dans l'app.
- `confidentialite.html` : la politique de confidentialité (adresse donnée aux magasins).

Aucune ressource externe, aucun traceur. Les liens de l'App Store et de TestFlight sont à
remplir en haut du script de `index.html` quand ils existeront.
